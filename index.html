Projects

Cartify

Cartify is a full-stack eCommerce web application built to deliver a smooth and modern shopping experience. It allows users to browse products, explore categories, and view detailed product information easily. The platform includes features like user authentication, cart management, and order placement. An admin panel is implemented to manage products, categories, and users efficiently.

The application focuses on clean UI design and responsive layout for better user experience. It is developed using Java, Spring Boot, Thymeleaf, MySQL, and Bootstrap. This project showcases my ability to build complete, scalable, and real-world web applications.




WeCare

WeCare, built in Java and employing the MVC architecture, efficiently handles hospital operations. It separates into Model (data and logic), View (user interface), and Controller (input handling), offering a modular and user-friendly solution for tasks like patient management, appointment scheduling, admin controls etc.




Weather-App

I developed a Weather App that allows users to check real-time weather updates by entering a city name. The application fetches live data from a weather API and displays key information such as temperature, humidity, and weather conditions.
This project helped me understand how to work with APIs, handle JSON data, and dynamically update the UI using JavaScript. I also focused on creating a responsive design using HTML, CSS, and Bootstrap.
